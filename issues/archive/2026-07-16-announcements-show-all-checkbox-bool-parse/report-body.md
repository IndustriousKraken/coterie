Symptom:
Selecting "Show all (up to 100)" on the Announcements page returns a generic error message to the top-right corner of the screen.

Steps to reproduce:
1. Login to Neon Temple Coterie.

2. Navigate to the Announcements page.

3. On the top of the page, click "Show all (up to 100) bubble.

4. A generic error message "An error occurred. Please try again" will be displayed at the top-right corner of the screen for each instance the "Show all" bubble is selected, regardless if a "filter by type" is selected. The message(s) will disappear from view after a few moments afterwards. 


Reference:
https://coterie.theneontemple.com/portal/announcements
