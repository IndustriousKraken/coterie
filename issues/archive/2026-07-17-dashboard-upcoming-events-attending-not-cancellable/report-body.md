Symptom:
Upcoming Events on the Dashboard doesn't allow cancelling registered events if selected prior on the Events page or if the Dashboard page is reloaded after selecting there "The Attending status is non-interactive". The user may only change this on the Dashboard by clicking "RSVP" which will allow them to update the selection without refreshing the page.

Steps to reproduce:
1. Login to Neon Temple Coterie. On the Announcements page, notice the Upcoming Events.

2. Navigate to the Events page.

3. Register for an event (skip to step 4 if already registered).

4. Navigate to the Dashboard page. A registered event from the step 3 will now be displayed but is non-interactive. The user can RSVP for new events and change the selection on this page without reloading. However, reloading the page will no-longer allow the user to change the RSVP status until manually navigating to the Events page to change the status.

Reference:
https://coterie.theneontemple.com/portal/dashboard

Version Tested:
Coterie v1.0.9 (latest release as-of 7/17/26).
