API keys

In the Stripe dashboard, go to Developers → API keys. Copy the Publishable key and the Secret key. Use test-mode keys (pk_test_/sk_test_) while setting up, then switch to live keys when ready.

Webhook signing secret

Under Developers → Webhooks, add an endpoint pointing at https://your-domain/api/payments/webhook/stripe, then copy its Signing secret (whsec_…). Without it, the webhook endpoint returns 503 — dues won't be credited on payment.

Rotating keys

Paste the new value and save. The running client and webhook verification switch over immediately — no restart. Leaving a secret field blank keeps the stored value.
